Claude APIDisclosed subprocessor, zero data retention.
  1. Connector sync writes Study data, then metrics and rules run, then flagged Sites go to the Agents, which write proposed Actions.
  2. A person approves an Action or a whole Campaign in the web app, and the email provider sends it.
  3. Site clicks and replies come back through Request pages and the inbound address; the Triage agent classifies them and extracts asks.
  4. Prime answers questions in the web app and Teams from stored results and read tools; it never starts a scan.
